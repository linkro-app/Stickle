# Stickle

**윈도우·리눅스·맥 바탕화면에 붙이는 메모 — 내 클라우드로 어느 컴퓨터에서나 같은 메모를.**

[English](README.md) · [홈페이지](https://stickle.linkro.co) ·
[Microsoft Store](https://apps.microsoft.com/detail/9MZ6BHN3JKFR)

> **현재 상태: 시험판.** 0.5 시험판이 나왔습니다. 윈도우와 리눅스에서 한 컴퓨터 안의
> 메모로 쓸 수 있고, 이제 되돌아갈 수 있는 매일 백업, 모든 메모 내보내기, 다른 메모 앱에서
> 가져오기가 있습니다. 컴퓨터 간 동기화는 아직 없습니다. [시험판 써 보기](#시험판-써-보기)를 보세요.
> 새 버전 알림을 받으려면 이 페이지 위쪽의 **Watch → Custom → Releases**를 눌러 주세요.
> 별표(Star)는 관심 표시일 뿐, 알림은 오지 않습니다.

## 왜 Stickle인가

- **계정도, Stickle 서버도 없습니다.** 이미 개인적으로 쓰고 있는 동기화 폴더(Dropbox, OneDrive,
  Google Drive, iCloud Drive, Syncthing, Nextcloud 등)로 동기화합니다. 메모는 저희를
  거치지 않으며, 저희가 읽으려 해도 읽을 수 없습니다.
- **처음부터 사생활을 지키도록 만들었습니다.** 메모는 내 컴퓨터에서 암호화되고,
  동기화에도 종단간 암호화를 켤 수 있습니다. 분석·통계 전송은 일절 없습니다. 그 밖에
  앱이 접속하는 곳은 하루 한 번의 업데이트 확인뿐이며, 이것도 끌 수 있습니다.
- **오프라인에서도 됩니다.** 네트워크가 끊겨도 모든 기능이 동작하고, 다시 연결되면
  자동으로 동기화합니다.
- **메모는 평범한 마크다운입니다.** `# 제목`, `**굵게**`, `==형광펜==`, `- [ ]`처럼 쓰면 서식이
  입혀진 모습으로 보이고, 체크 상자는 바로 누를 수 있습니다. 편집은 더블클릭. 메모는 어디서나
  읽히는 평범한 텍스트라 특정 형식에 묶이지 않습니다. 마크다운을 몰라도 그냥 글처럼 쓰면 됩니다.
- **메모가 모르는 사이에 사라지지 않습니다.** 두 컴퓨터에서 같은 메모를 고치면 두 버전을 모두
  남깁니다. 지운 메모는 1년 동안 휴지통에 남고, 암호를 잊어도 복구 키로 메모를 열 수 있습니다.
- **모든 기능이 무료입니다.** 광고도, 잠긴 기능도, 유료 등급도 없습니다. Stickle은
  자유 소프트웨어(GPL)이며 기부로만 운영합니다.
- **방해하지 않습니다.** 무언가를 요청하는 알림·배너·팝업을 띄우지 않습니다.
- **설치하면 바로 됩니다.** 따로 설치할 것이 없습니다. 필요한 라이브러리와 글꼴을 앱이
  함께 담고 있습니다. 입력기는 윈도우와 리눅스(fcitx5·IBus)에서 한글로 시험했습니다.

## 시험판 써 보기

시험판은 [Releases](https://github.com/linkro-app/Stickle/releases)에 *pre-release*로
올라옵니다. macOS용은 준비 중입니다.

- **윈도우**(10·11): [Microsoft Store](https://apps.microsoft.com/detail/9MZ6BHN3JKFR)에서
  받으세요. Microsoft가 서명하므로 경고 없이 설치되고 업데이트도 알아서 됩니다. Store판과 아래
  zip판은 같은 폴더(`%APPDATA%\Stickle`)에 메모를 두므로, 한쪽에서 다른 쪽으로 옮겨도 메모가
  그대로 이어집니다.

  또는 내 컴퓨터에 맞는 zip(`x64`, ARM 노트북이면 `arm64`)을 받아 아무 곳에나
  압축을 풀고 `stickle.exe`를 실행합니다. zip판은 아직 코드 서명이 없어서 윈도우가 "PC 보호" 창을
  띄울 수 있습니다. **추가 정보 → 실행**을 누르세요. **로그인할 때
  Stickle 시작**을 켜 두면 0.3에서는 Microsoft Defender가 `Trojan:Win32/Bearfoos.A!ml`로 막는
  경우가 있었습니다. 서명 없는 프로그램이 로그인 때 스스로 켜지는 것을 기계학습이 트로이 목마로
  잘못 추정한 것입니다. 0.4와 0.5는 최신 Defender에서 막히지 않는 것을 확인했지만, 빌드마다
  달라질 수 있어 코드 서명한 빌드가 나올 때까지 Windows에서는 이 항목이 꺼진 채로 시작합니다.
  Defender가 Stickle을 막았다면 [이슈](https://github.com/linkro-app/Stickle/issues/new)로 알려 주세요.
- **리눅스**: AppImage를 받아 실행 권한을 준 뒤(`chmod +x Stickle-x86_64.AppImage` 또는 파일
  속성에서) 실행합니다. Stickle이 앱 목록에 자신을 추가할지 묻습니다.
  자동 로그인을 쓰면 데스크톱의 키 모음이 잠긴 채로 남아서, Stickle이 로그인과 함께 켜질 때
  키 모음을 열기 위해 로그인 암호를 묻습니다. 키 모음을 쓰는 다른 앱도 마찬가지입니다. 피하려면
  자동 로그인을 끄거나, 로그인 키 모음의 암호를 비워 두세요.
- 처음 실행하면 몇 가지를 묻고 **복구 키**를 보여 줍니다. 이 컴퓨터가 아닌 안전한 곳에
  보관하세요. 이 컴퓨터에 저장된 키를 잃었을 때 메모를 여는 열쇠입니다.
- 받은 파일은 같은 릴리스의 `SHA256SUMS.txt`로 확인할 수 있습니다.

0.5.1에서 새로 된 것:

- 글을 모두 지운 메모는 숨기거나 지우면 휴지통을 거치지 않고 바로 사라집니다.
- Stickle 창에서 검색할 때 휴지통에도 맞는 메모가 있으면 알려 주고, **휴지통에서 보기**로 볼 수
  있습니다.
- 처음 실행하면 뜨는 환영 메모에 주요 기능과 기능 안내 링크를 더했고, Stickle 정보에서 빌드에
  들어간 모든 것의 오픈 소스 라이선스를 열 수 있습니다.
- 고친 것: 윈도우에서 Stickle 정보가 Stickle 창 뒤에 열리던 문제, `Tab`으로 간 링크에서 `Enter`를
  누르면 링크 대신 창이 닫히던 문제, 다른 프로그램을 쓰는 중에는 메모 단추의 풀이글이 뜨지 않던
  문제.

0.5에서 새로 된 것:

- **매일 백업**: 하루에 한 번 메모를 백업해 일주일 동안 보관합니다. 되돌아가려면 Stickle 창이나
  트레이 메뉴에서 **데이터 → 백업에서 되돌리기…**를 고르세요.
- **내보내기**: **데이터 → 모든 메모 내보내기…**로 메모마다 마크다운 파일 하나씩, 전체를 담은
  JSON 파일 하나를 함께 저장합니다.
- **메모 가져오기**: Microsoft Sticky Notes, Zhorn Stickies, xpad, Indicator Stickynotes에서
  가져옵니다(**데이터 → 다른 앱에서 메모 가져오기…**). 그 앱의 파일은 읽기만 하고 바꾸지 않습니다.
- **서식째 붙여 넣기**: 웹 페이지나 문서에서 복사한 굵게·목록·링크가 그대로 들어옵니다.
- **크기를 바꿀 때도 맞춤**: 옆 메모의 변 가까이에서 놓으면 변이 맞춰집니다. **자석처럼 메모
  정렬**로 옮길 때와 크기를 바꿀 때의 맞춤을 함께 켜고 끄며, `Alt`를 누른 채 놓으면 이번만
  건너뜁니다.
- **문제·제안 보내기…**: 트레이 메뉴와 Stickle 정보에 있습니다.
- **하루 한 번 업데이트 확인**: zip판과 AppImage는 하루 한 번 새 버전이 있는지 보고 Stickle 창에
  알립니다. 작은 파일 하나를 읽을 뿐 사용자에 관해 아무것도 보내지 않으며, **하루에 한 번 새 버전
  확인**으로 끌 수 있습니다. Microsoft Store판은 Store가 알아서 업데이트합니다.
- 트레이 아이콘을 더블클릭하면 새 메모가 생깁니다(시스템이 허용하는 곳에서). 업데이트 뒤에는
  바뀐 점을 메모 하나로 알려 줍니다.
- 0.4·0.3·0.2·0.1.2 시험판에서 만든 메모는 그대로 열립니다. 프로그램만 바꾸면 됩니다. 바꾸기 전
  메모의 사본은 메모를 저장하는 폴더의 `backups`에 남습니다(윈도우 `%APPDATA%\Stickle\backups`,
  리눅스 `~/.local/share/stickle/backups`).

0.4에서는 카테고리·표시 아이콘, Stickle 정보와 후원 방법, 메모를 숨기는 동안 흐려지는 트레이
아이콘이 더해졌습니다.
0.3에서는 카테고리와 표시, 바탕화면에 한 카테고리만 보기, 바탕화면에서 찾기, 나란히 붙는 메모,
편해진 목록과 코드 블록, 단축키 한눈에 보기(`F1`이나 `Ctrl+/`)가 더해졌습니다.
0.2에서는 검색, 휴지통, 어디서나 쓰는 단축키(`Ctrl+Alt+N`·`Ctrl+Alt+S`·`Ctrl+Alt+H`), 반투명·잠금
메모, 키보드만으로 조작, 아래의 포터블 모드가 더해졌습니다.

### 포터블로 쓰기

USB 메모리에 Stickle과 메모를 함께 들고 다니려면, 윈도우에서는 `-portable.zip`을 받아 아무
곳에나 압축을 풀고 `stickle.exe`를 실행하세요. 같은 프로그램에 `stickle.exe`와 나란히
`stickle-data` 폴더가 들어 있는 것입니다. 이미 쓰는 Stickle도 같은 방법으로 포터블이 됩니다.
`stickle.exe`가 있는 폴더(리눅스는 AppImage 파일이 있는 폴더)에 `stickle-data`라는 빈 폴더를
만드세요.

그러면 Stickle은 설정과 메모를 그 폴더에만 둡니다. 이 컴퓨터의 암호 저장소를 쓰지 않으므로 항상 암호를 묻고,
로그인할 때 켜지거나 앱 목록에 들어가지 않습니다. Wayland에서는 데스크톱에 맡겨야 하는
어디서나 쓰는 단축키가 없습니다.

시험판에서 되는 것과 안 되는 것:

- 메모는 이 컴퓨터에만 암호화되어 저장되고, 매일 백업도 같은 컴퓨터에 일주일 치가 남습니다.
  동기화는 아직 없어서 컴퓨터를 잃으면 백업도 함께 잃으니, 가끔 메모를 내보내 다른 곳에도
  두세요.
- 이후 버전도 시험판에서 만든 메모를 열 수 있게 할 계획이지만, 메모를 저장하는 방식이 아직
  바뀔 수 있고 시험판에는 버그가 있을 수 있습니다. 중요한 내용은 다른 곳에도 남겨 두세요.

## 시험을 도와주실 분께

지금 가장 도움이 되는 것은 실제 컴퓨터에서의 보고입니다. 특히 macOS, KDE, 흔하지
않은 리눅스 배포판, 여러 입력기, 다중 모니터·고해상도 환경의 보고를 기다립니다.
[이슈를 열어](https://github.com/linkro-app/Stickle/issues/new) 아래 내용을 적어 주세요.

- 운영체제와 버전, 리눅스라면 데스크톱(GNOME, KDE 등)과 입력기
- 무엇을 했고, 무엇을 기대했고, 실제로 어떻게 되었는지
- Stickle이 문제 화면을 보여 줬다면 **자세한 정보 복사** 버튼으로 복사한 내용
- 가능하면 로그 파일도 보내 주세요. 로그에는 메모 내용이나 폴더 경로 같은 개인 정보가
  들어 있지 않습니다.

| 시스템 | 로그 파일 |
| --- | --- |
| 윈도우 | `%APPDATA%\Stickle\logs\stickle.log` |
| 리눅스 | `~/.local/share/stickle/logs/stickle.log` |
| macOS | `~/Library/Application Support/Stickle/logs/stickle.log` |

## 소스에서 실행하기

[uv](https://docs.astral.sh/uv/)를 설치한 뒤:

```
uv sync
uv run python -m stickle
```

시험: `uv run pytest`
