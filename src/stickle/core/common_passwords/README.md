# Common passwords

Passwords too common to protect anything, refused as a master password
(`stickle.core.passwords`).

- `common-passwords.txt`: the 10,000 most common passwords, one a line, from
  SecLists (`Passwords/Common-Credentials/10k-most-common.txt`, commit
  913b327317496d062bcc7cace524aaad8a693be2), under the MIT License in `LICENSE`.
  Kept as it came.
- `korean.txt`: Korean words and phrases often used as passwords, written for
  Stickle (GPL-3.0-or-later, as Stickle). They are refused as written and as
  typed on an English keyboard with the Korean input off (안녕 as `dkssud`).
